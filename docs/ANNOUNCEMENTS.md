# 公告发布

读者可从主导航进入「公告」，阅读公开消息和创作提醒。首页默认展示最多 3 条公开公告，置顶消息优先，其余按最近发布时间排列；没有公开公告时收起首页公告区域，完整列表仍提供空态引导。管理员可在 [首页展示](HOME_OPERATIONS.md) 调整首页公告的数量、顺序和展示开关。

## 编辑和发布

管理员从账号菜单进入「公告管理」，按标题、完整 ID 或状态查找公告。点击「新建公告」填写标题、摘要、正文和处理理由，先保存为编辑稿，再预览并确认发布。

标题最多 160 个 Unicode 字符，摘要选填、最多 300 字，正文最多 20,000 字，理由最多 2,000 字。正文以纯文本展示，保留换行，标签等文字按原文显示。

编辑稿和公开内容分别保存。修改已公开公告后，读者继续看到上次发布的标题、摘要、正文和置顶状态；管理员再次确认发布后，公开页面和首页才使用新内容。列表显示最近发布时间，首次发布时间保留在公开 API 中。

发布、撤回、归档和恢复都先核对确认内容。撤回或归档后，公告退出公开页面、首页和站点地图；恢复后保留编辑稿，需要管理员明确重新发布。

## 重试和冲突

网络失败时，面板保留输入，使用原操作标识重试。出现并发冲突时，点击「核对最新公告」，查看最新状态和正文，明确采用最新修订后逐项核对当前保留的输入，再手动提交。

离开未保存的面板前会提示确认，请在处理中的操作结束后再关闭。桌面和手机都可打开编辑面板，预览、确认内容及长理由可以滚动和键盘访问。

每次创建、保存、发布、撤回、归档或恢复均追加操作记录，包含操作人、理由、标题、状态、修订和正文字数；记录只读，不展示邮箱或账号凭据。

## API 和数据维护

公开接口为 `GET /api/v1/announcements`、`GET /api/v1/announcements/:id` 和 `GET /api/v1/site/announcement-sitemap`，仅返回已公开快照。列表每页最多 20 条，公开响应禁止缓存，详情不可访问时返回 `404 NOT_FOUND`。

管理接口位于 `/api/v1/admin/announcements`，提供列表、创建、详情、修改、记录及 `publish`、`withdraw`、`archive`、`restore` 状态操作。使用有效管理员会话；写入需要 CSRF、UUID 格式的 `Idempotency-Key`，修改和状态操作还需公告对应的 `If-Match`，状态操作需明确提供 `confirmed: true`。完整参数见 [OpenAPI](openapi.json)。

相同标识重试相同请求只处理一次，改变请求后复用标识返回冲突；修订过期返回 `412 REVISION_CONFLICT`。公告最多保留 2,000 条，归档仍保留原 ID、编辑稿、发布快照和记录，可恢复维护原公告。

新增迁移 `0029_announcements.sql` 只增加公告和操作记录表，沿用追加式记录保护。维护前按 [数据维护](OPERATIONS.md) 保存一致备份，需要回退时同时评估应用版本和对应数据库备份，保留原业务目录。
