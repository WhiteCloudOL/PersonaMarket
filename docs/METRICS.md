# 公开统计与导出口径

作品数和创作者数只包含当前仍有已审核公开版本的作品；隐藏、下架或失去公开资格后，统计读取立即排除该作品

导出数表示服务器已准备好并开始提供导出响应，不代表读者已保存文件或已在机器人中成功安装。导出预览、HEAD 文件头查询、格式错误、缺失素材和无权访问不会增加计数

同一主体、同一作品、同一 UTC 日期的多个格式与版本，只增加一次作品导出数；版本与格式另保留各自的去重日汇总。作者导出自己的作品会保留展示计数，排行榜使用的计数排除本人导出

登录主体按有效账号去重；匿名读者使用当天到期的签名 Cookie，不采集 IP、浏览器 UA 或长期设备指纹。匿名去重属于近似统计，清除 Cookie、换浏览器或退出账号仍可能产生额外计数

去重摘要按 UTC 日保留最近35天并分批清理；不含主体标识的日汇总长期保留，清理摘要不会减少历史总数。统计从功能启用后开始记录，不推算启用前的下载量

公开接口只返回数量，不返回去重摘要、Cookie、账号或风控细节。作品内容与导出继续执行实时公开权限校验，统计不会赋予额外访问权限
