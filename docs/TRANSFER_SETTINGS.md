# 导入导出设置

管理员可从「网站设置 → 导入导出」维护访客下载、可用文件格式和导入大小。普通业务配置使用有效管理员会话；已主动绑定二次验证的账号仍需先完成登录验证。

## 设置与生效范围

「允许未登录访客导出」控制本站的导出预览和文件下载，包含历史公开版本的下载地址。关闭后需要登录再导出，公开详情仍可阅读和手动复制。

导入和导出格式分开选择，可全部关闭。关闭格式后，新文件预览、未完成预览的确认以及文件下载使用当前限制；已保存的草稿、公开版本与历史记录不会被删除或截断。旧预览仍可读取和取消，确认前需核对当前格式是否开放。

文本、JSON 和原生文件的业务上限可设为 64–4096 KiB，完整 ZIP 为 1–128 MiB。原始上传按文件字节计算；TXT / Markdown 映射提交按确认的映射内容计算，不保存被丢弃的原文。历史预览若缺少原始大小记录，收紧上限后需重新预览。

上传入口、正文总量、ZIP 展开、图片、权限与资源归属校验继续执行，管理员设置只允许收紧既有固定上限。文件大小设置不改变已经保存作品的正文限制。

## 保存与冲突处理

常用开关直接显示，格式通过标签切换，文件大小和修改记录按需展开。点击「保存导入导出设置」提交表单。预览默认设置只填入表单，保存后生效。

并发编辑的独立字段自动合并，同一字段发生冲突时保留输入，确认后再次保存。

请求结果未知时可核对服务器修订，原内容不变的重试复用同一操作标识。服务器已有后续修订时，页面不会把后续结果冒充本次提交。未保存输入仅在当前账号的浏览器内存中暂存，刷新、关闭、切换账号或退出后不保留。

## API

| 请求                                                 | 用途                                       |
| ---------------------------------------------------- | ------------------------------------------ |
| `GET /api/v1/settings/transfer`                      | 当前公开策略及修订，不含修改人、理由或审计 |
| `GET /api/v1/admin/settings/transfer`                | 管理员设置、默认值及当前修订               |
| `PATCH /api/v1/admin/settings/transfer`              | 保存设置                                   |
| `GET /api/v1/admin/settings/transfer/records?page=1` | 分页读取只读修改历史                       |

管理读取返回 `ETag: "transfer-N"`。写入提供对应的 `If-Match`、UUID `Idempotency-Key` 和当前会话的 CSRF 头；可携带 `X-Expected-Account` 核对账号，此头不授予权限。修改、修订、历史与审计在同一事务内提交，提交事务重新核对实际身份。公共读取与导出内容不使用公共缓存。完整请求和响应结构见 [OpenAPI](openapi.json)。

## 升级与维护

版本化迁移 `0043_transfer_settings.sql` 为旧预览增加可空的原始字节数，并仅在配置不存在时插入默认策略，不覆盖已有配置。旧预览不会通过猜测正文大小补写原始文件大小。执行迁移前按 [数据维护](OPERATIONS.md) 备份，保留旧应用镜像；迁移执行后不得修改其内容或通过删除配置行恢复默认。需要回到默认策略时，在管理表单预览并保存。
