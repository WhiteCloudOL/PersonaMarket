# 公开索引与分享

首页、探索、人设排行、使用指南和公开作品提供独立标题、简介、Canonical URL、Open Graph 与 Twitter 分享信息。作品使用已审核版本的标题、简介与站内图片；没有作品图片时使用站点品牌图。

Next.js 可将普通浏览器的异步元数据以流式形式追加到文档，支持 JavaScript 的爬虫可以读取这些标签。仅抓取静态 HTML 的社交机器人会等待元数据，并在初始 `head` 中获得分享信息；检查时分别使用实际浏览器 DOM 和对应机器人 User-Agent 的初始响应。

## 地址与索引策略

`PUBLIC_ORIGIN` 是所有绝对公开地址的唯一来源，例如站点实际运行的 HTTPS 域名。它只接受不带凭据、路径、查询或 fragment 的 HTTP/HTTPS origin。请求自带的 Host 或 Forwarded-Host 不用于构造 Canonical URL。

生产模式中的 HTTPS 域名允许公开页面进入索引；本机地址、IP、非生产模式及 `localhost`、`local`、`internal`、`test`、`invalid`、`example` 保留后缀保持禁止索引。本地 HTTP 预览仍可查看元数据和站点地图，不会因此宣称站点已对公网开放。

| 页面                                   | Canonical URL                         | 索引                                   |
| -------------------------------------- | ------------------------------------- | -------------------------------------- |
| 首页、默认探索、指南                   | 各自固定地址                          | 公开环境允许                           |
| 搜索、组合筛选与探索分页               | 探索页地址                            | `noindex`                              |
| 有限的榜单、平台与适用窗口组合         | 省略快照与页码的榜单地址              | 公开环境允许；快照和分页地址 `noindex` |
| 当前公开作品                           | `/personas/{id}`                      | 公开环境允许                           |
| 不可变公开版本                         | `/personas/{id}/releases/{releaseId}` | `noindex`，分享信息保留具体版本        |
| 登录、账号、工作台、后台、审核与错误页 | 不提供作品公开元数据                  | `noindex`                              |

作品的「分享」按钮会在复制前重新核验该版本可公开访问，并复制固定版本地址。作品后续更新后，这个链接仍指向原版本；访问权限仍由服务端实时判断。

## 站点地图

`/sitemap.xml` 返回站点地图索引，包含 `/sitemaps/static.xml` 与 `/sitemaps/personas/{page}.xml`。作品分片每页最多 1000 项，按作品 ID 稳定排列，覆盖全部当前公开作品，不使用探索或排行榜的前 1000 项展示上限。

每条作品只提供当前作品地址及当前获批版本的真实发布时间。私有草稿、待审内容和历史版本不加入站点地图，草稿自动保存也不会改变地图中的修改时间。

页面、元数据、站点地图与素材访问均保留实时可见性检查；地图响应使用 `no-store`，服务读取失败返回可重试的 503，不将连接失败当作空地图。部署前置缓存时，保持动态公开页面和站点地图的响应缓存策略。

公共数据接口为 `GET /api/v1/public/sitemap/index` 和 `GET /api/v1/public/sitemap/entries?page=1`，请求和响应见 [OpenAPI](openapi.json)。索引与分片共用每个真实访客每分钟 120 次的限流，每个数据库读取语句最多两秒；一个索引最多包含 49999 个作品分片和一个固定页分片。

`/robots.txt` 给出对应运行环境的抓取规则。robots 与 noindex 仅指导爬虫，私有内容仍由原有身份和资源权限保护；第三方已经下载或缓存的内容无法由本站强制收回。

Next.js 的流式错误文档在页面开始传输后可能保持 HTTP 200，并通过不可访问页面与 `noindex` 告知爬虫该地址不可索引，部分抓取工具会将其称为 soft 404。作品 API、素材与导出接口在内容不可公开时仍返回 404；监测公开性时同时核对接口状态、HTML 的 `noindex`、作品元数据和正文是否缺席。站点地图读取失败使用明确的 HTTP 503。

## 公告的公开边界

`/announcements` 提供公开公告列表，`/announcements/:id` 的标题、简介、Canonical 和分享信息来自已发布快照，保存编辑稿不会提前改变读者看到的文字。公告详情首次发布和最近发布的时间分别保留，分享元数据使用最近一次实际发布时间。

固定页分片 `/sitemaps/static.xml` 包含公告列表及全部当前公开公告，公告条目使用实际发布时间作为修改时间。数据来自 `GET /api/v1/site/announcement-sitemap`，最多 2,000 条，与公告总量上限一致；读取失败返回 503，撤回或归档后立即移除条目。

不可公开的公告 API 返回 404，Web 页面沿用上述流式错误处理，显示不可访问状态和 `noindex`，标题、摘要及正文不进入错误文档。分页列表使用列表首页作为 Canonical，后续分页带 `noindex`。
