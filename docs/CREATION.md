# 人设创作与草稿

从导航中的「发布」或「我的人设 → 创建人设」打开完整创作表单，依次填写基本信息、平台和正文，再补充可选模型、图片、README 与来源许可。未登录时可以先填写，登录后再保存与上传素材。每个人设只对应一个平台，保存后不可改为另一平台。

MaiBot 使用人格设定、表达风格、行为风格三个独立字段。AstrBot 使用人格设定和按用户/AI 配对的预设对话；可以不添加对话，移动、复制与删除以整对为单位。

首次创建前，平台切换会分别保留 MaiBot 与 AstrBot 的正文；「创建私有草稿」一次保存当前平台及完整资料，随后进入自动保存的编辑器。创建页的「创建版本」会先检查必填项，再保存草稿并打开版本确认，不会直接公开。

主要分类从站点预设中选一个。作品标签可从推荐里选，也可输入名称后按回车或点「添加标签」。推荐与自定义标签合计最多 8 个。自定义标签随作品审核，作品公开后可用于广场筛选。

已有草稿的编辑内容会在短暂停顿后自动保存到服务器，也可点击「保存草稿」。空字段可以暂存，正文及首尾空白原样保留。字数按 Unicode 字符计算，页面展示当前发布上限，硬边界超限需修改后才能保存。

桌面宽屏右侧展示实时预览和检查摘要，手机和平板从顶部「预览」打开抽屉。可用「定位首个问题」继续完善，也可通过「查看全部检查」展开完整清单并定位对应字段；展开或收起不影响已填内容。编辑器的保存说明在完整清单中查看，预览仅展示当前输入，不会调用模型生成对话或产生公开互动数据。

新建表单提示登录时，点击「去登录」会在当前标签页登录并自动返回，已填资料和两个平台正文在本标签页内存中保留 30 分钟；已绑定二次验证的账号须先完成验证。刷新或关闭标签页会清除这份临时内容，换账号或主动退出也会清理。

遇到断网或登录失效时，内容继续保留在当前页面，可重试保存；已有草稿的编辑器也支持在另一窗口重新登录后重试。离开有未保存修改的页面会提示确认，使用新建表单内的登录入口可直接往返。重新载入服务器草稿会丢弃本地未保存编辑，请先复制本地草稿备份。

同一浏览器的多个窗口会同步账号变化：访客首次登录和原账号重新登录保留新建表单；切换到另一账号会清空本地创作内容、平台切换缓存、来源缓存及编辑器撤销历史。主动退出时，其他窗口的创作页面返回首页；已保存的私有草稿仍归原账号所有。

同一人设在多个页面编辑时，版本冲突会阻止覆盖。请先比较或备份当前编辑，再明确选择重新读取服务器内容；不要通过反复刷新覆盖另一页面的修改。退出账号后，私有查询缓存会清理。

## README、图片与来源

图片上传、在线导入和新送审的图片数量使用站点当前配置。素材库和头像入口会提示当前限制，站点可以收紧下列固定上限；已有素材和旧公开版本继续保留。设置与计量方式见 [文件与图片设置](MEDIA_SETTINGS.md)。

README 使用 Markdown 编辑器，可切换实时预览。编辑器、预览和内容展示使用统一安全渲染，HTML 与危险协议不会执行；外站图片只显示待导入提示。

公开作品的 README 包含多个标题时，可打开「章节目录」定位正文。章节地址绑定当前阅读的已发布版本，复制地址后可直接返回同一章节；作者发布新版后，原地址仍指向旧版本。

人设头像可在表单直接上传，支持小于 10 MiB 的静态 JPEG、PNG、WebP。服务器保留宽高均不超过 512 像素的 WebP，原图和元数据不会写入存储。其他作品图片单张最多 5 MiB，所有图片解码上限为 4000 万像素。处理后的图片保存在私有素材库。README 使用 `asset://素材ID` 引用本站图片。

在线图片点击导入后，由任务下载并保存托管快照，仅接受公网 HTTPS 的默认端口，拒绝凭据、内网与不安全重定向。导入失败会显示原因类别，可修正地址后重试；原站后续修改不改变本站已保存图片。每账号最多 100 张、100 MiB 素材，同时最多 3 个在线导入任务。

授权证据可以留空，上传时最多关联 5 份，只供发布者和相关审核人员查看。

推荐模型可选填最多 5 条。来源区必选原创或转载及转载许可，原作者、来源链接、来源说明、授权依据和自定义许可说明均可选填。提交前需确认有权提交内容并授权站点展示和提供复制下载。

## Release 与公开作品

完成草稿后选择「创建 Release」。站点先等待最新内容保存，再展示本次公开信息供核对。填写稳定语义版本号（如 `1.0.0`）与更新日志，确认后提交审核。邮箱需要已验证，正文、来源与素材须符合当前投稿设置。

送审快照保留名称、简介、正文、README、图片引用、推荐模型、来源许可和作者说明。继续修改草稿不会影响这次审核或已发布版本，每个人设同时只能有一个待审核提交。版本号按数值比较，必须高于历史最高已发布版本；例如 `1.10.0` 高于 `1.9.0`，已发布版本号不能复用。

在「发布记录」查看每次提交及意见。被驳回或主动撤回后，可以继续编辑并使用同一未发布版本号重新提交，旧快照与意见会保留。复制历史快照前会展示与当前服务器草稿的差异，确认后按该修订号替换；请先备份其他页面尚未保存的编辑。另一页面同时保存时会阻止覆盖，须重新读取和核对。

管理员或审核员从「内容审核」查看提交内容、与当前版本的逐字段差异、私有授权证据和审核记录。驳回需要明确意见。审核员不能审自己的作品，管理员自审需要勾选确认、填写理由，并在十分钟内验证身份；未绑定 MFA 时使用近期密码登录或当前密码确认，已绑定时使用动态码或恢复码。过期验证在当前页面完成，审核输入会保留，确认身份后由管理员再次提交。并发审核或作者同时撤回时，仅一个决定生效。

通过审核后，版本会成为当前公开版本，可从首页、人设广场和详情页阅读。新的更新等待审核期间，旧公开版本继续可用；历史版本各自保留当时的内容和来源。

作者可以隐藏整个作品、恢复展示、选择仍有效的历史版本作为当前版本，或撤销某个已发布版本。当前版本被撤销或屏蔽时，站点不会自动选择旧版替代，需要作者明确选择安全版本。管理员封禁会阻止全部公开入口与再次送审，解除封禁不会改变作者隐藏状态；版本屏蔽解除也不会自动切换公开指针。

## 投稿设置

管理员可在「站点设置 → 创作与投稿」管理投稿开关、开放平台、每人每日配额、平台正文上限与待审提示。每日次数按 UTC 自然日统计，重提计入配额，相同操作的幂等重试不重复计数。

关闭投稿或某个平台阻止新建作品与新送审，已有草稿仍可编辑，旧公开版本继续可用。降低业务上限不会截断历史或草稿，重新送审时按当前上限校验。设置采用版本冲突保护，并记录管理员操作。

待审提示最多 500 个 Unicode 字符，支持换行并按纯文本显示。留空可隐藏额外说明，待审标签、撤回与继续编辑入口仍保留。提示仅用于本人真实待审版本，提交成功后及发布记录页面会读取当前提示和配置修订；修改提示不改变不可变版本正文，也不改写已发送的通知或邮件。审核已结束时显示状态更新入口，不沿用旧提示。

保存时核对两组修订并填写处理理由，投稿策略修改记录可展开核对前后值。版本冲突时保留输入，读取最新修订并明确采用后再次保存；网络结果未知时先「核对原提交结果」，随后输入仍保留。该核对复用原幂等标识，已成功请求不会再次写入。

升级兼容仅覆盖旧 PATCH 载荷省略 `pendingHint` 时保留当前配置，不会将自定义提示重置为默认值。新响应包含新增字段，部署后请刷新使用新页面；旧版严格响应解析的前端包不能无缝读取新增字段。旧修改记录缺少提示字段时显示「当时未配置此字段」，不会回写历史。

## 查找、复制与导出

导出面板按站点当前设置显示可用格式；需要登录时会提示登录，全部适用格式关闭时会说明原因。下载与历史版本链接同样执行当前设置，公开正文仍可阅读和手动复制。

探索页支持组合选择平台、分类、标签、推荐模型、原创或转载、转载规则，并按发布时间或名称排序。筛选、分页、搜索和卡片/列表视图保存在 URL 中，可刷新或分享；选项与数量来自已审核的当前公开版本。

详情先展示作品介绍，通过「人设内容」阅读平台正文，通过「来源与许可」核对使用规则。没有作品介绍和作者说明时直接展示正文。作品资料保留发布者、分类、转载规则和推荐模型，模型说明按需展开；「查看版本记录」打开历史面板，选择版本后正文、复制和导出都对应所选版本。MaiBot 三段分别复制；AstrBot 可复制人格、单对或全部对话；「复制人设」获取完整可读文本，「分享」复制当前版本链接。浏览器拒绝剪贴板时提供可选中文本供手动复制。

「导出」先预览再下载，可选可读文本、Markdown、通用 JSON、完整 ZIP 包，以及 MaiBot 人格 TOML 片段或 AstrBot 原生 JSON。面板说明每种格式的用途与省略内容，下载前由服务器重新检查版本公开资格；历史版本使用当时的冻结正文，已隐藏、撤销或封禁内容不能继续请求导出。

MaiBot 目标版本为 1.3.15，TOML 片段只包含 `[personality]` 下 `personality`、`reply_style`、`behavior_style`，请按目标机器人配置方式合并。AstrBot 目标版本为 4.29.3，使用其 WebUI「人格」文件导入入口；该平台会移除系统提示词首尾空白，并采用目标平台的工具与 Skills 默认设置，请在目标端核对和限制能力。

原生格式、可读文本和 Markdown 只承载平台正文，预览会列出省略的作品资料。Markdown 使用分段标题与代码围栏保留正文，适合阅读和整理文档。

通用 JSON 文件以 `.persona.json` 结尾，保留作品资料、分类标签名称、正文、README、推荐模型、来源与许可，图片使用源站引用清单。文件中的图片引用需在导入时确认和托管，适合携带完整资料；不会恢复站内账号身份、审核记录、互动统计或私有授权证据。文件结构见 [通用格式说明](PERSONA_FORMAT.md)。作品的转载许可仍有效，请在使用与分享时保留来源说明。

完整 ZIP 文件以 `.persona.zip` 结尾，包含通用清单、README、作品来源许可说明和该版本实际使用的图片，适合离线保存与迁移。清单预览保留包内图片相对路径，下载时逐张校验图片；文件较大时可取消下载并重试。作品声明与私有资料的边界和通用 JSON 相同。

## 导入通用 JSON 与完整 ZIP

导入入口展示站点当前开放的格式与大小上限。管理员可以收紧限额或关闭某种格式；以下大小为固定上限，实际可用额度以页面当前设置为准。预览后设置发生变化时，确认保存会重新核对；旧预览仍可读取和取消，必要时重新选择文件。设置规则见 [导入导出设置](TRANSFER_SETTINGS.md)。

从「我的人设 → 导入人设」打开「通用 JSON / ZIP」，选择或拖入一个文件，按「选择文件 → 核对内容 → 保存草稿」逐步确认。通用 JSON 最大 4 MiB，完整 ZIP 最大 128 MiB，预览会列出正文、README、分类标签、模型、来源与图片清单。

完整 ZIP 会校验并托管包内图片；通用 JSON 的在线图片需要逐张明确确认导入，或上传与清单校验值匹配的原图。不会在浏览器中自动访问文件里的图片地址。所有图片完成托管后才能继续；失败时可重试本张图片，重新选择文件会取消当前预览。

核对来源后填写转载依据，选择新建私有草稿或明确替换自己的同平台草稿。返回核对不会清空本次输入，保存失败会保留表单；替换前会检查目标修订号，其他页面的更新不会被静默覆盖。导入只保存草稿，不会自动发布或取得源文件声明的原创身份。

预览初始有效期为 30 分钟，主动确认图片导入或成功补图可以续期，最长到创建预览后的 60 分钟。预览过期后重新上传文件即可；关闭页面不会自动保存未确认的内容，切换账号会清理当前窗口的私有输入。

## 导入原生文件

从「我的人设 → 导入人设」切换到「平台原生文件」，选择 MaiBot TOML 或 AstrBot JSON，上传最大 4 MiB 的文件并预览。MaiBot 整份配置只提取三个人格字段；AstrBot 仅提取人格与偶数条交替的用户/AI 对话。其他账号、密钥、工具与运行权限配置会丢弃，文件原文不会作为备份保存。

原生文件和独立的通用 JSON 支持 UTF-8、GBK、GB18030、UTF-16 LE/BE。默认优先识别 BOM 或严格 UTF-8，必要时尝试 GB18030 并提醒核对正文；自动识别无法保证判断所有旧编码，预览乱码时手动切换后重试，无 BOM 的 UTF-16 请手动选择字节序。预览会显示实际读取编码，保留作者首尾空白与换行；大小按上传原始字节计算，超过 4 MiB、编码冲突或无效字节明确拒绝。ZIP 包遵守通用格式内部编码约定，无需选择文本编码。

预览仅当前账号可用，30 分钟后过期并由后台分批清理。核对正文、忽略字段，填写名称和文件来源，确认后默认新建私有草稿；也可以选择自己的同平台草稿，按明确提示替换全部正文与元数据。目标草稿在确认期间被另一页面保存时会阻止覆盖，公开版本不受影响。

原始文件大小与保存后的正文资料分别校验。原生预览和最终草稿的正文及相关资料合计最多 4 MiB；旧编码转为 Unicode 后可能占用更多空间，填写来源也会增加资料体积。超限时页面会保留输入并提示减少内容，正文不会被自动截断。

导入不会取得原作者身份、审核状态或公开资格。草稿默认按转载处理，仍需补齐原作者、来源与许可、勾选授权，再主动创建 Release 提交审核。

## 导入 TXT 与 Markdown

从「导入人设 → TXT / Markdown」选择不超过 4 MiB 的文件，明确选择 MaiBot 或 AstrBot，再读取原文。编码选项与原生文件相同，支持 UTF-8、GBK/GB18030、UTF-16 LE/BE；乱码时更换编码重新读取，界面会先确认是否清除当前映射。

原文按只读文本显示，Markdown 标记与内嵌 HTML 不会执行，也不会自动猜测字段。用鼠标、触控或 Shift + 方向键选中段落，再点击对应字段的「选中文本填入」；也可选择「全文填入」，或直接粘贴、编辑字段。填入会替换该字段的当前内容，原文空白与换行保留；字段超限会提示修改，不自动截断。

MaiBot 需要独立核对人格设定、表达风格和行为风格。AstrBot 需要系统提示词，预设对话按用户消息和 AI 回复成对添加，可不添加对话。确认映射后生成仅当前账号可用的 30 分钟预览，再填写名称、来源并新建或明确替换自己的私有草稿；返回修改映射会保留名称和来源说明。

完整原文件不落盘，只有明确确认的映射字段进入临时预览与最终草稿；未映射内容不会保存。取消或请求失败时当前输入仍保留，切换账号会清理私有输入；关闭页面后未确认的映射不自动保存。
