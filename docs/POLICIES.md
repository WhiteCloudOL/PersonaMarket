# 公共规则管理

管理员在「网站设置 → 公共规则」分别维护三份文档，读者从页脚进入当前公开版

| 文档           | 公开地址          |
| -------------- | ----------------- |
| 服务条款       | `/terms`          |
| 隐私说明       | `/privacy`        |
| 投稿与转载规则 | `/content-policy` |

新站初始化只建立空草稿。运营者填写实际适用的条款、来源与转载说明、隐私和举报联系渠道，经审核批准后公开。后台维护入口为 `/admin/settings/policies`，`document` 查询参数保留当前选择

## 编辑、送审与批准

1. 选择文档，填写标题、简短介绍和 Markdown 正文，用预览核对阅读效果
2. 选择「保存规则草稿」。保存只更新草稿
3. 选择「提交规则审核」，核对已保存内容并填写送审理由。系统冻结这次正文和来源修订，每份文档同时保留一份待审快照
4. 审核人从「查看待审快照」核对冻结内容，再选择批准或驳回。待审期间继续编辑草稿，不会改变这份快照

批准后，这份快照成为当前公开版。待审、驳回、撤回或继续保存草稿时，已有公开版继续展示。驳回须说明理由；审核他人的版本时，批准理由可以留空

标题最多 160 字，介绍最多 300 字，正文最多 30,000 字，理由最多 2,000 字，按 Unicode code point 计数。草稿可以暂不完整，送审时要求标题和正文非空。正文保留作者填写的空白，通过统一安全 Markdown 阅读组件展示

## 管理权限与自审

公共规则由管理员维护，作品审核员角色不自动获得此权限。有效管理员会话可以编辑草稿、查看记录、审核他人快照和管理公开版

本轮实际编辑者和送审人参与自己的审批时，须勾选自审确认、填写明确理由，并完成十分钟内的身份验证。已绑定 MFA 的账号使用 MFA；未绑定的账号使用当前密码确认。验证在当前弹层中进行，完成后保留理由，由操作者再次确认原操作

编辑者谱系在送审时冻结。驳回、撤回或换人送审不清除未批准的编辑记录；送审之后的新编辑仍计入下一轮。保存完全相同的内容不会创建新的编辑修订

## 历史版本与下线

「查看历史与处理记录」按需展开送审状态、批准版本和修改记录，列表只展示摘要，选择对象后读取正文与详情

批准快照不能修改。恢复旧版本时选择历史中的批准快照，通过「激活这个批准版本」确认公开切换；当前草稿和其他待审快照保留原内容。相同正文已有批准版本时，直接激活该版本

「管理当前公开版 → 下线当前公开版」停止公开展示，批准历史和草稿继续保留。公开链接中的 `publicationId` 只核对当前批准指针，切版或下线后，旧地址不能继续获取旧正文。页面上的「查看当前公开版」会重新读取当前状态

公开页显示本次公开时间，重新激活旧版本时同时显示首次发布时间。目录来自实际 Markdown 标题，章节链接绑定版本；手机目录以抽屉展开，选择章节后回到正文

## 冲突与结果核对

两个管理员同时编辑时，保存会自动合并不同字段。同一字段发生冲突时保留表单内容，再次点击保存可确认提交。审核等状态操作遇到冲突会读取当前状态，再由操作者重新选择。

网络中断而结果未知时，页面保留原操作和幂等标识。草稿通过「保存规则草稿」重试，审核等操作可以核对原提交结果。

未保存的草稿、理由和原请求仅在当前账号的网页内存中暂存，切换文档或设置组后可以返回继续，刷新网页后不保留。账号退出、变化或权限失效时按会话边界处理私有状态

## API

完整请求和响应结构见 [OpenAPI](openapi.json)，所有地址以 `/api/v1` 为前缀

| 方法与路径                                                                  | 用途                   |
| --------------------------------------------------------------------------- | ---------------------- |
| `GET /policies`、`GET /policies/:slug`                                      | 当前批准规则摘要与正文 |
| `GET /admin/settings/policies`、`GET /admin/settings/policies/:slug`        | 管理摘要和当前编辑状态 |
| `PATCH /admin/settings/policies/:slug`                                      | 保存草稿               |
| `POST /admin/settings/policies/:slug/submissions`                           | 冻结并送审             |
| `GET /admin/settings/policies/:slug/submissions`、`GET .../submissions/:id` | 送审摘要与冻结正文     |
| `POST .../submissions/:id/withdraw`、`POST .../submissions/:id/review`      | 撤回或审批             |
| `POST .../actions/unpublish`、`POST .../actions/activate`                   | 下线或激活批准版本     |
| `GET .../records`、`GET .../records/:id`                                    | 修改处理摘要和前后状态 |

私有写请求使用登录会话、CSRF、同文档 `If-Match: "policy-<slug>-<revision>"` 和 UUID `Idempotency-Key`。`X-Expected-Account` 只核对实际登录账号。权限、状态、谱系和近期身份由 API 在事务内复查，记录和幂等回执随业务一并提交
