# 查找与阅读人设

在「探索」中搜索人设名称、简介、标签、作者或公开 README，也可输入作者填写的推荐模型名称

## 组合筛选

- 平台：MaiBot 或 AstrBot
- 分类与标签：分类单选；标签最多同时选择8个，作品必须包含所有已选标签
- 推荐模型、原创或转载、作者的转载规则
- 首次发布时间：最近7天、最近30天或全部
- 预设对话：包含 AstrBot 对话，或没有预设对话
- 精选状态：精选作品、未设精选或全部作品

搜索、平台和排序直接展示，分类、标签与其他条件放在「高级筛选」；手机点击「筛选」，选好后通过「查看结果」应用，也可关闭面板放弃本次选择。已选条件会汇总展示，便于逐项移除

条件、排序、页码与卡片/列表视图保存在地址中，可复制浏览器地址分享给他人，刷新后仍保留这些条件

首页的「精选人设」展示管理员选中的公开作品，「查看全部精选」带你进入对应筛选；隐藏、下架或失去公开资格的作品不会进入推荐结果。API 使用 `featured=true` 或 `featured=false`，未提供时包含所有公开作品，详见 [OpenAPI](openapi.json)

在首页「新近发布」选择「全部」「MaiBot」或「AstrBot」即可筛选已公开的新作，刷新、分享地址和浏览器返回会保留选择。「查看全部」带你进入同一平台的探索结果，精选人设和社区统计保持各自范围

## 排序与结果

相关度排序优先匹配名称与精确标签；未输入关键词时按最近首次公开排列。「最近发布」按作品第一次公开的时间排列，「最近更新」按当前公开版本的发布时间排列；补丁发布不会把作品变成新作

「有效导出」按累计有效导出量排列，「近7天导出」统计今天及此前6个 UTC 日期。同一主体、同一作品每天最多计一次，多格式与多版本导出合并去重，作者本人导出不计入；并列时按首次公开时间与作品 ID 稳定排序

这两种排序的作品卡片显示相应有效导出量，可与搜索和筛选一起使用。导出量表示服务端成功提供导出响应，不表示已完成保存或安装；排行榜的定时快照可能稍晚于探索页的实时计数

「近期热度」与新版热门榜共用 `interactions-v1` 口径：近7×24小时有效点赞×3、收藏×4、导出×1，分别按事件年龄以7天半衰期衰减。卡片显示实际互动热度和各项有效数量，浏览和评论不计入热度

「有效点赞」「有效收藏」按当前有效关系排序，参与账号须正常且邮箱已验证，并排除作者本人；卡片显示用于排序的有效数量，可能与包含本人互动的展示总数不同。取消重加保留首次时间，收藏者身份保持私有

探索即时计算，排行榜按定时快照读取，因此两者可能有时间差。没有有效互动的作品仍在探索结果中，同分时优先展示最近首次公开的作品；完整规则可在「统计说明」展开，也可阅读 [排行榜口径](RANKINGS.md)

搜索最多展示前1000个结果，结果较多时可以增加关键词或筛选条件。搜索耗时较长或读取失败时，可缩小范围后重试；没有匹配结果时，可使用「清空筛选」重新探索

结果只展示已审核且可公开的作品。作者编辑中的内容在发版并审核通过前不会进入搜索；作品隐藏或下架后也会退出公开结果

## 查看作品

点击卡片阅读当前公开版本，核对平台、来源、推荐模型和作者的转载政策。历史版本保留各自的内容与声明，可在作品页查看、复制和导出
