# 首页展示

管理员在「网站设置 → 首页展示」调整首页短提示、模块顺序、展示数量和主导航。站名和简介继续在「站点品牌」中维护。

## 模块和数量

首页保留站点介绍，其余模块可通过「上移」「下移」调整顺序，或关闭对应的展示开关。排序按钮支持鼠标、触控和键盘。

| 模块     | 展示内容                           | 默认数量 | 可设置上限       |
| -------- | ---------------------------------- | -------- | ---------------- |
| 精选人设 | 管理员选中且当前可以公开访问的作品 | 4        | 1–12             |
| 新近发布 | 最近首次公开的作品                 | 4        | 1–12             |
| 站点公告 | 已发布的公告快照，置顶消息优先     | 3        | 1–5              |
| 创作入口 | 平台入口、创作步骤和创作者入口     | —        | 按整组展示或收起 |

精选和公告没有可展示内容时收起对应区域，新作模块为空时提供创作引导。数量是上限，页面展示实际符合条件的内容；隐藏、下架的作品和未发布、已撤回、已归档的公告不会因此变得可公开访问。

## 主导航

首页和探索始终保留。可选择排行、发布、指南、公告入口，并调整这些入口的展示顺序。桌面导航和手机导航使用相同配置，收起入口不会关闭对应功能，也不会授予访问权限。

保存后，公开配置立即更新，访客重新加载页面时使用新配置。设置读取失败时，首页显示重新加载提示，主导航保留首页和探索入口。

## 保存和核对

填写处理理由后保存，后台会追加修改人、时间、修订及修改前后的完整差异。点击「查看修改差异」核对具体内容，记录只读。

「预览默认设置」先对照当前输入和默认内容；「填入默认值」只更新表单，填写理由并保存后才对公开页面生效。

请求失败时保留当前输入，重试使用原操作标识。遇到并发修改时，读取最新配置，明确采用新修订后逐项核对保留的输入，再手动保存。

重试返回的配置与当前输入不同时，会先展示最新修订供核对，并保留当前输入；确认采用修订号后再手动保存。

同一页面会话内离开再返回会暂存未保存的输入；刷新页面后不保留。切换账号、角色变化或主动退出会清理私有缓存。

## API 和数据维护

公开配置接口为 `GET /api/v1/site/home`，返回受控文字、模块目录、数量和导航选项，不返回管理员资料。公开响应使用 `no-store`，读取失败不伪装成默认配置。

管理接口为 `GET /api/v1/admin/settings/home`、`PATCH /api/v1/admin/settings/home` 和 `GET /api/v1/admin/settings/home/records?page=1`。使用有效管理员会话，修改需要 CSRF、UUID 格式的 `Idempotency-Key` 及对应的 `If-Match: "home-修订号"`。相同请求重试只处理一次，修订过期返回 `412 REVISION_CONFLICT`。

修改记录每页 20 条，页面可浏览最近 2,000 条，较早记录仍保留在数据库中。记录仅包含首页配置及理由，不记录 SMTP 密钥等敏感设置。完整参数见 [OpenAPI](openapi.json)。

新增迁移 `0030_home_settings.sql` 增加设置记录表及首页默认设置，同名现有配置会保留。维护前按 [数据维护](OPERATIONS.md) 保存一致备份，同时保留原业务目录。
