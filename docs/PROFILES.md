# 个人资料和创作者主页

从账号菜单进入「个人资料」，维护公开昵称、头像、简介和最多五个公开链接。邮箱、密码、登录设备和二次验证继续在账号安全页面管理，不会出现在创作者主页。

账号菜单中的「公开主页」可以直接打开当前账号的创作者页，尚无获批资料时展示安全默认资料。

## 编辑和发布

保存草稿只更新本人编辑区。提交审核会冻结当时的资料快照，后续编辑不会混入该次审核；同一账号同时只能有一份待审快照。可以撤回待审资料，修改后重新提交。

审核通过后，公开主页才会切换到获批资料。等待审核或退回调整期间，原获批资料继续展示；尚无获批资料时展示用户名和安全默认头像。公开简介按纯文本显示，链接只接受 HTTP(S) 地址。

「审核历史」可查看每次提交的冻结内容和审核结果，「处理记录」保留提交、撤回、审核及隐藏恢复的记录。切换分区会保留当前编辑输入。其他窗口已经保存时，需要读取并核对最新草稿，明确采用后继续，页面不会自动覆盖。

## 头像和公开资格

选择 JPEG、PNG 或 WebP 图片后，在「裁切头像」弹窗中移动和缩放方框内的图片。确认后上传裁切结果，服务器只保存处理后的 WebP。保存草稿并提交审核后，头像会随获批资料公开。

头像通过统一图片服务处理并保存在私有存储中，不能以远端图片地址绕过审核。公开头像地址绑定获批快照；换版、隐藏资料或账号不再满足公开条件后，旧地址不能继续读取。用于举报的冻结头像另由举报私有权限保护。

公开地址为 `/users/用户名`，展示实际获批资料及该作者当前可公开访问的人设。可按 MaiBot 或 AstrBot 筛选并分页，条件保留在地址中。隐藏资料时使用安全默认资料，作品仍按各自状态判断；封禁或停用账号的公开主页不可访问。

## 审核和管理

审核员和管理员从账号菜单进入「资料审核」，按完整用户名、审核状态和页码查找提交，打开面板核对冻结快照。处理说明会向作者展示，切换处理记录不会丢失未提交意见。

审核员可审核他人的资料，本人资料应交由其他审核员或管理员处理。管理员自审需要明确确认、具体理由和十分钟内的身份验证。普通审核他人资料和浏览队列不追加近期验证。

隐藏或恢复获批资料仅管理员可操作，要求近期身份验证并填写理由。已绑定 MFA 时必须使用 MFA；未绑定时可用当前密码确认。验证在当前页面完成，保留意见，由管理员再次核对并重试原操作。

## 举报

在公开主页点击举报，提交的是当前实际看到的获批快照。举报详情、冻结资料和头像仅举报人本人及管理员可读。管理员处理旧举报时不能直接隐藏后来获批的新资料，需要核对目标版本。完整流程见 [举报和处理](REPORTS.md)。

## API

| 路径                                                 | 用途                       |
| ---------------------------------------------------- | -------------------------- |
| `GET/PUT /api/v1/me/profile`                         | 本人资料工作区与乐观锁保存 |
| `GET/POST /api/v1/me/profile/submissions`            | 提交列表与创建冻结快照     |
| `GET /api/v1/me/profile/submissions/:id`             | 本人的提交详情             |
| `POST /api/v1/me/profile/submissions/:id/withdraw`   | 撤回待审快照               |
| `GET /api/v1/me/profile/records`                     | 本人的处理记录             |
| `GET /api/v1/admin/profiles/submissions`             | 审核队列                   |
| `GET /api/v1/admin/profiles/submissions/:id`         | 审核快照详情               |
| `GET /api/v1/admin/profiles/submissions/:id/avatar`  | 审核范围内的私有头像       |
| `POST /api/v1/admin/profiles/submissions/:id/review` | 审核指定快照               |
| `POST /api/v1/admin/profiles/:userId/visibility`     | 隐藏或恢复获批资料         |
| `GET /api/v1/admin/profiles/:userId/records`         | 审核范围内的处理记录       |
| `GET /api/v1/users/:username`                        | 安全公开资料               |
| `GET /api/v1/users/:username/personas`               | 作者当前公开作品           |
| `GET /api/v1/users/:username/avatar/:id`             | 当前获批快照的公开头像     |

写入需要有效会话和 CSRF；提交、撤回、审核和隐藏恢复另需 UUID `Idempotency-Key`。草稿、提交和公开资格分别使用自己的修订号。`X-Expected-Account` 只核对当前账号，不赋予权限；头像上传也会在写文件前拒绝账号不符的请求。完整请求和响应以 [OpenAPI](openapi.json) 为准。

审核结果通过站内通知交付，审核邮件遵循账号现有通知偏好。资料、审核记录和私有头像属于数据库及私有文件的备份范围，维护方法见 [数据维护](OPERATIONS.md)。
