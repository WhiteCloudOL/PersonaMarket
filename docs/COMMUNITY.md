# 人设互动与评论

登录并验证邮箱后，可以在公开作品卡片和详情页点赞或收藏。选中的图标会填充，再次点击可以取消；键盘也可以聚焦按钮并使用回车或空格操作。

点赞和收藏关联整个人设，切换公开版本或查看历史版本时仍使用同一份关系与计数。数量以服务端返回的当前有效关系为准，正常且已验证邮箱的账号参与计数，作者自己的操作也会显示在总数中。

## 我的收藏

打开右上角账号菜单，选择「我的收藏」。收藏列表仅本人可见，其他人访问同一个页面地址只能查看自己的列表。

可以按作品名称、平台和可用状态筛选，按收藏时间、作品更新时间或名称排序。筛选和页码保留在地址中，刷新或返回后可以继续查看；名称与平台筛选只匹配当前可公开的作品。

作品隐藏或下架后，收藏中显示「作品暂不可用」占位，保留收藏时间和移除操作。占位不会显示旧标题、正文、图片或作者信息，移除只影响自己的收藏。

收藏时间使用首次添加的时间，取消后重新添加仍保留该时间。重复请求不会增加同一账号的关系数量，也不会刷新首次时间；个人收藏时间与后续版本更新时间分别保留。

每页最多 20 项，最多翻阅 500 页；收藏较多时可使用名称或平台缩小范围。

## 站点互动开关

管理员可在「站点设置 → 社区互动」分别控制新增点赞与收藏。关闭后保留已有记录和真实计数，用户仍可取消自己的记录；直接调用新增接口也会检查开关。

评论有独立的「开放新建和编辑评论」与「展示已有公开评论」开关。暂停写入后，作者仍可删除自己的评论；暂停展示不删除原文或审核记录，待审文本仍只向作者和有权限的审核人员提供。

评论默认全部审核后公开。管理员也可选择「关闭预审，自动批准」，每次自动批准仍保留系统审核记录。字数上限可设为 1–2000 个 Unicode 字符，每人每分钟允许提交 1–30 次，默认上限为 2000 字、每分钟 5 次；新建和编辑共同计入提交频率。

保存使用版本校验。如果其他管理员已经修改设置，页面会保留当前选项并提示冲突；选择「读取最新社区设置」查看服务端的新值，确认保留的选项后再次保存。

离开未保存的设置时会提示确认。浏览和调整这组业务配置使用有效管理员会话，已绑定身份验证器的账号仍需先完成登录验证。

## 评论与回复

在作品详情的「作品评论」中交流体验。登录并验证邮箱后可提交评论，纯文本保留换行与空白，HTML 与 Markdown 标记按普通文字展示。评论关联整个人设，可以保留提交时对应的公开版本；作品更新后讨论和原版本引用继续保留。

楼层采用两层结构，回复同一楼层中的评论会保留回复对象。公开评论、楼层回复和「我的评论」各自分页，排序、页码与展开的楼层保留在地址中。公开列表与回复每页最多 20 条，最多 2500 页；自己的列表每页展示 5 条。

新评论显示在「我的评论」中，审核通过后其他用户才能读取正文。编辑会建立新的待审文本，旧的获批文本继续公开；驳回新文本也不覆盖旧获批内容。管理弹层展示当前审核状态和理由，保存冲突时保留输入，可读取最新快照后自行核对、再次提交。

作者删除评论后，已公开楼层保留删除占位，其他人无法读取删除前的正文或作者信息。管理员隐藏的评论、不可用账号的评论也使用安全占位；回复仍保留所属楼层。作者删除不能由管理员恢复为公开正文。

## 评论审核

审核员与管理员从账号菜单进入「评论审核」，按作品、状态与提交顺序筛选，查看最新待审文本、旧获批文本和处理记录。每次决定针对明确的文本快照；作者已修改或其他审核人员已处理时返回冲突，需要重新读取并核对。

批量审核最多选择 20 条，先核对完整文本，再确认决定。结果逐条显示，成功条目不会随失败重试再次处理；读取失败条目最新快照后，理由会保留，已处理或不可审核的条目移出选择。

审核员不能处理本人评论。管理员自审需要明确确认、理由和十分钟内的身份验证；已绑定 MFA 使用动态验证码，未绑定时使用当前登录密码。验证在当前页面完成，原理由与输入保留，验证后由管理员再次提交原操作。普通审核他人评论不要求额外近期验证。

管理员可以隐藏评论，或恢复符合条件的已隐藏评论，处置需填写理由。隐藏与恢复保留审核记录，恢复本人评论同样执行管理员自审验证。

## API 与访问边界

完整结构见 [OpenAPI](openapi.json)。所有写入需要有效会话及 CSRF 校验，服务端会再次检查邮箱、账号状态、资源可见性和站点开关。

| 方法与路径                                    | 用途                                                                               |
| --------------------------------------------- | ---------------------------------------------------------------------------------- |
| `PUT /api/v1/personas/:id/like`               | 设置为已赞                                                                         |
| `DELETE /api/v1/personas/:id/like`            | 取消点赞                                                                           |
| `PUT /api/v1/personas/:id/favorite`           | 设置为已收藏                                                                       |
| `DELETE /api/v1/personas/:id/favorite`        | 取消收藏，支持移除本人以前收藏的不可用作品                                         |
| `GET /api/v1/me/persona-interactions?ids=...` | 批量读取本人的互动状态、真实计数和开放状态，最多 50 个 ID                          |
| `GET /api/v1/me/favorites`                    | 本人的收藏列表，支持 `q`、`platform`、`availability`、`sort`、`page` 和 `pageSize` |
| `GET /api/v1/admin/settings/community`        | 管理员读取当前互动设置和 ETag                                                      |
| `PATCH /api/v1/admin/settings/community`      | 管理员携带 `If-Match: "community-N"` 更新开放状态                                  |
| `GET /api/v1/personas/:id/comments`           | 读取公开一级评论、计数和评论设置                                                   |
| `POST /api/v1/personas/:id/comments`          | 创建评论或楼层回复，可附同作品公开 `releaseId`                                     |
| `GET /api/v1/comments/:id/replies`            | 分页读取一级楼层的公开回复                                                         |
| `GET /api/v1/me/comments`                     | 按 `personaId` 分页读取本人的评论与审核状态                                        |
| `GET /api/v1/me/comments/:id`                 | 读取本人单条评论的最新文本与版本                                                   |
| `PATCH /api/v1/comments/:id`                  | 携带 `expectedRevision` 编辑本人评论，建立新审核文本                               |
| `DELETE /api/v1/comments/:id`                 | 携带 `expectedRevision` 删除本人评论                                               |
| `GET /api/v1/admin/comments`                  | 有权限的审核队列                                                                   |
| `GET /api/v1/admin/comments/:id`              | 审核详情与处理记录                                                                 |
| `POST /api/v1/admin/comments/:id/review`      | 核对 `revisionId` 和 `expectedRevision` 后通过或驳回                               |
| `POST /api/v1/admin/comments/bulk-review`     | 最多 20 条逐项审核，返回每项成功或失败结果                                         |
| `PUT /api/v1/admin/comments/:id/visibility`   | 管理员隐藏或恢复评论                                                               |

点赞和收藏使用 PUT／DELETE 明确设置状态，重复发送相同操作保持幂等。请求体可以为空或为 `{}`，不接受客户端传入账号、权限或计数。写入按账号限制为每分钟 30 次，并受共享的请求来源限制；超出时返回 429 和 `Retry-After`。

批量状态只返回当前可公开的人设。不存在、隐藏、下架或无权访问的作品统一按访问规则拒绝，移除本人已有的不可用收藏只返回安全的移除状态。私人查询和公开计数均使用禁止公共缓存的响应。

收藏查询受两秒语句预算保护，查询超时返回 503 和 `Retry-After`，可以稍后重试或缩小筛选范围。

评论写入需要 `Idempotency-Key`，相同键和相同请求重试不会重复创建评论或审核记录，不同内容使用新键。评论查询使用 `page`、`pageSize` 与 `sort=oldest|newest`；审核队列另支持 `personaId` 和 `status=PENDING|APPROVED|REJECTED|hidden|all`。

可选请求头 `X-Expected-Account` 用于核对当前实际会话是否仍属于预期账号，不能指定身份或取得权限。评论页面私有请求携带此条件，账号切换后清理旧账号的私有查询与表单。会话临时失效时保留当前未提交输入，同账号完成登录后可继续。

新评论未提交时，当前标签页可以短期保留输入，同一作品内翻页、切换评论排序或展开回复后可继续编辑；离开作品或切换版本时会提示确认。临时内容最多保留三十分钟，刷新、关闭页面、主动退出或换账号会清除；长时间离开前请先提交，提交后的待审文本保存在「我的评论」中。

评论事务设置三秒 SQL 语句预算，数据库繁忙时返回安全的 503 与 `Retry-After`，不会将未完成事务作为成功提交。应用层还限制同账号短时间内的重复正文，所有频率与幂等检查由服务端执行。

## 举报问题内容

在公开人设详情或公开评论中提交举报，从账号菜单的「我的举报」跟进处理状态。补充说明仅自己和管理员可读；管理员在「举报处理」核对内容快照、记录处理说明和内部备注，操作方式及数据边界见 [举报和处理](REPORTS.md)。

## 升级与数据保留

迁移 [0023_persona_interactions.sql](../packages/database/migrations/0023_persona_interactions.sql) 新增独立的点赞与收藏关系表、唯一约束及索引，并初始化互动开关。升级前按 [数据维护](OPERATIONS.md) 备份数据库和私有文件，再执行现有 Compose 迁移流程。

现有账号、MFA、草稿、Release 与图片继续保留。互动关系属于数据库备份范围，公开版本的不可变正文不因互动操作改变。

迁移 [0024_comments.sql](../packages/database/migrations/0024_comments.sql) 增加评论、不可变文本版本与追加式审核记录，以及关联、两层楼层和公开指针约束。新增评论设置与旧互动设置合并，原点赞、收藏开关的值保留。评论与审核记录同样纳入数据库备份，升级前按上述数据维护流程备份。
