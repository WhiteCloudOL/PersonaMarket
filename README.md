## 使用体验

面向 MaiBot 与 AstrBot 的人设创作与分享空间，在手机、平板或电脑上轻松访问

| 体验               | 使用方式                                                                                  |
| ------------------ | ----------------------------------------------------------------------------------------- |
| **邮箱账号**       | 注册账号、验证邮箱，使用用户名或邮箱登录，忘记密码时通过邮件重置                          |
| **账号与安全**     | 修改密码、确认新邮箱，管理登录设备与二次验证，提交或撤回停用申请                          |
| **创作者主页**     | 编辑昵称、头像、简介和公开链接，审核后更新主页，展示自己的公开作品                        |
| **人设创作**       | 为 MaiBot 分段编写性格、表达与行为，为 AstrBot 编排人格和成对对话，自动保存私有草稿       |
| **图文与来源**     | 用 Markdown 讲述角色故事，上传图片，记录推荐模型、原作者与转载许可                        |
| **版本与分享**     | 主动创建 Release，跟进审核意见，管理公开版本、历史版本与作品展示状态                      |
| **作品分享预览**   | 分享固定版本的作品链接，通过真实标题、简介与封面呈现社交预览                              |
| **发现与阅读**     | 搜索人设、作者、标签与 README，组合筛选，按互动热度、有效点赞收藏、导出或发布时间发现作品 |
| **人设排行**       | 按热门、点赞、收藏、下载、新作和更新发现公开作品，切换平台与时间范围，分享榜单链接        |
| **复制与导出**     | 逐段复制角色正文，下载文本、Markdown、通用 JSON、含图片的 ZIP 包或平台原生格式            |
| **文件导入**       | 预览通用 JSON、完整 ZIP 与两平台原生文件，或手动映射 TXT/Markdown，核对来源后保存私有草稿 |
| **点赞与私有收藏** | 在作品卡片和详情点赞、收藏，按平台与状态整理仅自己可见的收藏                              |
| **评论与回复**     | 交流作品体验，查看楼层回复和版本引用，在自己的评论中跟进审核结果与修改                    |
| **举报与处理**     | 举报公开人设、评论或创作者资料，私下补充问题线索，在自己的记录中跟进处理状态和说明        |
| **通知中心**       | 接收审核、公开回复、处理进展和账号安全提示，管理未读状态及审核邮件偏好                    |
| **管理员设置**     | 管理站点品牌、邮件、注册会话、创作投稿与互动开关，身份验证器按需绑定                      |
| **管理概览**       | 按权限进入待审队列，管理员查看公开作品、近七天互动及真实任务和文件观测                    |
| **账号管理**       | 搜索用户、核对状态与管理记录，按明确范围调整角色、封禁账号或撤销会话                      |
| **作品管理**       | 核对作品版本，设置官方或精选标记，确认上下架、批量处理并查看操作记录                      |
| **创作目录**       | 维护分类和标签的名称、排序、启用状态，核对引用后归档或恢复目录                            |
| **站点公告**       | 阅读公开消息和创作提醒，管理员核对编辑稿后发布、撤回或归档公告                            |
| **使用指南**       | 阅读两平台教程和创作说明，管理员预览编辑稿、确认发布并核对修订记录                        |
| **首页展示**       | 调整首页模块顺序、展示数量和导航入口，预览默认设置并核对修改记录                          |
| **主题偏好**       | 在右上角选择跟随系统、浅色或深色，再次访问时沿用你的选择                                  |
| **多端阅读**       | 页面随屏幕宽度调整布局，长文本自然换行                                                    |
| **本地运行**       | 通过 Docker Compose 启动站点，运行数据集中保存在项目的 `data/`                            |

## 开始使用

在「创作工作台」为 MaiBot 或 AstrBot 创建人设，分段编辑角色内容，自动保存私有草稿；AstrBot 对话支持整对复制和排序，操作方式见 [创作指南](docs/CREATION.md)

在首页浏览精选人设，在「探索」中组合精选、标签、模型和来源条件，按相关度、首次发布或最近更新寻找角色，也可分享保留筛选条件的链接，详见 [查找与阅读人设](docs/DISCOVERY.md)

首页展示当前公开人设、创作者与有效导出数量，统计范围和去重方式见 [公开统计与导出口径](docs/METRICS.md)

在「排行」查看真实有效互动、导出与发布记录生成的榜单，分页保留同一批结果，也可刷新查看最新一批，计算规则见 [人设排行榜](docs/RANKINGS.md)

作品分享信息保留对应版本，公开站点可通过站点地图发现当前公开作品，地址与索引策略见 [公开索引与分享](docs/SEO.md)

为喜欢的人设点赞或收藏，在右上角账号菜单进入「我的收藏」，按平台、名称和作品状态整理相遇的角色；在作品详情交流体验、回复评论并跟进审核状态，详见 [人设互动与评论](docs/COMMUNITY.md)

在账号菜单进入「个人资料」编辑公开介绍，审核期间保留原获批内容；点击「公开主页」查看资料和自己的公开作品，详见 [个人资料和创作者主页](docs/PROFILES.md)

发现公开内容有问题时，从人设详情、评论或创作者主页提交举报，在「我的举报」跟进处理进度；管理员可核对内容快照和私有线索、记录处理说明，详见 [举报和处理](docs/REPORTS.md)

1. 选择「注册」填写用户名、邮箱和密码，手机可先打开「登录」再选择「创建账号」
2. 打开验证邮件中的链接，在页面上确认验证邮箱
3. 使用用户名或邮箱登录，打开右上角的账号菜单，在「账号与安全」中管理设备和二次验证

身份验证器支持标准六位 TOTP 动态验证码，绑定时请将一次性恢复码保存到安全位置；验证或重置链接失效后，可以重新申请邮件

密码支持 12–64 个字符，可使用独特的长口令；在「密码与邮箱设置」更新密码或确认新邮箱后，所有设备需要重新登录

管理员可从「账号与安全」进入「站点设置」，调整名称与简介、配置邮件并发送测试邮件，管理注册、会话和创作投稿策略；通过「内容审核」核对作品，通过「评论审核」核对文本、批量处理并查看审核记录，身份验证器可按需绑定

从账号菜单进入「管理概览」，优先处理待审内容，按需查看统计口径和运行详情，详见 [管理概览](docs/ADMIN_OVERVIEW.md)

在账号菜单进入「用户管理」，查看用户公开作品与审核记录，按角色、状态或待处理停用申请查找用户，核对账号后调整权限、处理会话或审核停用申请，详见 [账号与权限管理](docs/USER_MANAGEMENT.md)

在「人设管理」按作者、平台、分类和状态查找作品，核对版本后调整官方或精选标记，填写理由并确认上下架，也可批量处理所选作品、逐项核对结果，详见 [人设管理](docs/PERSONA_MANAGEMENT.md)

在「分类管理」和「标签管理」整理创作目录，停用旧选项、调整展示顺序或恢复归档条目，历史作品保留原有名称，详见 [分类和标签管理](docs/TAXONOMY_MANAGEMENT.md)

从主导航进入「公告」阅读站点消息，管理员可在「公告管理」保存文字稿、预览并确认发布，修改编辑稿时保留读者当前看到的内容，详见 [公告发布](docs/ANNOUNCEMENTS.md)

在「网站设置 → 首页展示」调整首页模块、展示数量和主导航，先预览默认值再决定是否保存，详见 [首页展示](docs/HOME_OPERATIONS.md)

创作时可以从「站点模型建议」选取模型信息，也可自由填写名称和备注；管理员在「网站设置 → 模型建议」调整列表，详见 [模型建议](docs/MODEL_SUGGESTIONS.md)

在「文档」按章节查找教程或分享独立文章，管理员从账号菜单进入「指南内容」编辑、预览并确认发布，详见 [指南内容管理](docs/GUIDES.md)

## 本地运行

准备 **Docker**、**Docker Compose 5.5.1** 和 **Node.js 26.13.0**，在项目根目录打开终端

Node.js 用于生成本机配置，站点运行环境由容器准备

### 1. 生成本机配置

首次运行时执行：

```sh
node scripts/init-env.mjs
```

命令会生成包含随机凭据的 `.env`，请妥善保存这份配置；已有 `.env` 的目录可直接从下一步开始

### 2. 启动站点

```sh
node scripts/build-images.mjs
docker compose -f compose.yaml -f compose.dev.yaml up -d --wait
```

### 3. 打开浏览器

访问 **[http://127.0.0.1:8080](http://127.0.0.1:8080)**，即可在这台电脑上浏览站点

本地运行使用 Mailpit 接收注册和密码重置邮件，收件箱位于 **[http://127.0.0.1:18025](http://127.0.0.1:18025)**；请使用测试邮箱地址，本地邮件只保存在这台电脑

配置真实 SMTP、开放注册与创建管理员的操作见 [容器运行指南](docs/DEPLOYMENT.md)

暂停站点时执行：

```sh
docker compose -f compose.yaml -f compose.dev.yaml stop
```

再次执行第 2 步中的 `up -d --wait` 命令即可启动，`data/` 中的数据会保留

## 数据与配置

Docker Compose 将项目目录直接绑定到容器，数据库、私有文件和服务状态集中在 `data/`，方便查看与备份

```text
data/
├── postgres/       PostgreSQL 数据
├── redis/          Redis 持久化数据
├── mailpit/        本地测试邮件
├── storage/        私有文件
├── caddy/
│   ├── data/       证书与服务数据
│   └── config/     Caddy 运行配置
├── backups/        本地备份
├── cache/          维护工具缓存
└── tests/          隔离验证数据
```

环境变量、域名与 HTTPS 配置、更新和数据维护方式，参见 [容器运行指南](docs/DEPLOYMENT.md) 与 [数据维护指南](docs/OPERATIONS.md)
