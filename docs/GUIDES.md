# 指南内容管理

读者在「文档」查看使用教程，也可通过 `/guides/maibot`、`/guides/astrbot` 等独立文章地址阅读和分享。原有 `/guides#章节` 链接继续定位当前公开章节。

## 编辑和发布

管理员从账号菜单进入「指南内容」，按标题或状态筛选章节，再打开编辑面板。现有九个业务章节提供固定地址。「开源许可」章节提供项目 GitHub 仓库链接，许可证和第三方致谢由项目许可及清单维护。

标题支持 1–160 个 Unicode 字符，简介选填、最多 300 字，Markdown 正文支持 1–30,000 字，处理理由支持 1–2,000 字。正文按原样保存空白；标题和简介使用单行文字。

桌面编辑和预览并排展示，手机通过「编辑正文」「查看预览」切换。预览复用公开页的安全 Markdown：HTML 不执行，链接限制为安全协议，图片只使用受控素材地址并遵循公开访问权限。外链图片显示提示，不直接抓取外部地址。

填写理由后先「保存编辑稿」，再点击「发布指南」核对已保存正文并确认。编辑稿变化不会替换读者正在阅读的内容，只有明确发布才生成新的公开版本。

「撤回指南」先展示当前公开稿，确认后从目录、独立文章和站点地图移除此章节。编辑稿、历史发布版本和处理记录仍保留，当前面板尚未保存的输入也会保留。再次公开需要核对后主动发布。

## 重试和修订记录

网络失败后保留输入，相同操作使用原标识重试。若重试时服务器已有后续修订，面板展示最新内容并保留本地编辑；点击「采用最新修订继续核对」后逐项核对，再手动提交。

并发冲突时可点击「核对最新指南」，读取最新状态和正文。采用修订只更新核对基准，不自动替换正在填写的内容。

关闭面板、页面前进或后退时，未保存输入保留在当前登录的内存中；刷新浏览器或退出账号前请先保存。账号切换、退出或角色变化会清理私有查询状态。处理中的请求有超时，失败后可核对服务器状态再重试。

每次保存、发布或撤回都追加只读记录，包含操作人、理由、变更前后正文、状态、修订和公开版本信息。记录每页 20 条，展开后可核对文字与校验值。

## API 和数据维护

公开接口为 `GET /api/v1/site/guides`、`GET /api/v1/site/guides/:slug` 和 `GET /api/v1/site/guide-sitemap`，仅返回当前已公开快照。公开读取禁止缓存；未公开或已撤回章节的详情 API 返回 `404 NOT_FOUND`。读取失败时显示可重试错误，不用旧正文恢复已撤回内容。

管理接口位于 `/api/v1/admin/guides`，提供列表、详情、修改、`publish` / `withdraw` 操作及记录。写入需要有效管理员会话、CSRF、UUID 格式的 `Idempotency-Key` 和对应 `If-Match: "guide-章节-修订"`；发布和撤回还需 `confirmed: true`。有效管理员会话可以维护指南，主动绑定 MFA 的账号仍需完成登录 MFA。完整契约见 [OpenAPI](openapi.json)。

相同标识和请求只处理一次，复用标识改变内容返回冲突；修订过期返回 `412 REVISION_CONFLICT`。身份、角色、修订、快照、处理记录与审计在事务中共同校验和写入。

迁移 `0032_guides.sql` 增加指南编辑稿、不可变发布快照和追加式记录表，并将原有九章教程作为首次公开内容保存。既有账号、人设、设置和上传目录不变。数据维护按 [数据维护指南](OPERATIONS.md) 保存一致备份，并保留对应应用版本。
