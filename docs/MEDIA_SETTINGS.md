# 文件与图片设置

管理员可从「网站设置 → 文件与图片」维护图片来源、大小、账号预算、README 图片数量和在线来源域。开关常驻，容量与来源域按需展开，修改后点击保存。

## 来源和已有素材

本地上传包含作品图片、资料头像、私有授权证据、通用包手动补图和完整 ZIP 内图。在线导入由独立开关控制；本地关闭时仍可开放在线导入，在线关闭时也可保留手动上传。两种方式均保留既有格式、真实解码、像素、文件、权限及私有证据检查。

关闭上传或收紧预算不会删除已有文件、截断草稿或改变旧公开版本。已经保存的素材仍可读取、引用或移除。未完成的通用包预览仍可读取和取消，继续托管或确认时使用当前限制；不满足新预算时需核对、释放暂存占用或重新预览。

## 容量与数量

| 设置               | 范围        | 计量方式                                                       |
| ------------------ | ----------- | -------------------------------------------------------------- |
| 单张原图           | 64–5120 KiB | 本地上传、ZIP 内图、手动补图和远程原始字节；5 MiB 固定上限保留 |
| 每账号素材数       | 1–100 张    | 正式作品素材、头像、证据及通用包暂存图片合计                   |
| 每账号存储预算     | 1–100 MiB   | 已归一化文件与暂存图片合计，待处理图片按声明字节预留           |
| 新版本 README 图片 | 0–20 张     | 实际 Markdown 图片语法计数，重复引用也计数；头像与封面另计     |
| 在途在线导入       | 1–3 个      | 普通图片与通用包图片的排队、处理任务合计                       |

未清理的暂存图片计入预算，取消或到期清理后释放。配额在用户锁内检查，配置在事务内重新读取，两个上传不能通过并发绕过名额。文件转换后的体积可能与原图不同，账号存储预算按实际归一化大小复查。

README 数量约束作用于新版本送审，草稿可以保留原文继续编辑，旧审核快照继续展示。代码块中的图片示例不计数，实际重复图片语法分别计数。

收紧在途总量不会删除已接受任务，新入队和受控重试使用当前预算。关闭在线导入、改变来源域或减小图片大小时，尚未生成素材的任务会在下载和保存阶段重新核对策略，失败状态可在本人导入结果或管理员任务页查看。

## 在线来源域

每行一个域名，最多 50 个。留空表示不额外限制域名，公网 HTTPS、逐跳地址和文件检查继续执行。域名精确匹配，不自动包含子域；需要 `images.example.com` 时应单独填写。

支持国际化域名，大小写、尾点与等价的 IDNA 名称视为同一域，重复输入会被阻止。不要填写协议、端口、路径、IP 或通配符。表单允许编辑时保留空行，提交时忽略空行。

来源域约束按 URL 主机名执行，每个重定向目标都需符合当前配置；保存素材的事务会再次核对已访问的来源。它不替代公网地址、TLS、实际连接及图片内容校验。

## 修订与 API

有效管理员会话可以维护此业务配置。点击「保存文件与图片设置」提交表单。并发编辑的独立字段自动合并，同一字段发生冲突时保留输入，确认后再次保存。恢复默认值先预览差异，填入表单后仍需保存。

| 请求                                              | 用途                                   |
| ------------------------------------------------- | -------------------------------------- |
| `GET /api/v1/settings/media`                      | 公开能力及修订，不含修改人、理由或秘密 |
| `GET /api/v1/admin/settings/media`                | 管理员配置、默认值及元数据             |
| `PATCH /api/v1/admin/settings/media`              | 原子保存配置、历史与审计               |
| `GET /api/v1/admin/settings/media/records?page=1` | 只读修改记录                           |

管理读取返回 `ETag: "media-N"`。写入提供相应 `If-Match`、UUID `Idempotency-Key` 和会话 CSRF 头，可用 `X-Expected-Account` 核对实际账号，此头不授予权限。完整契约见 [OpenAPI](openapi.json)。

存储驱动、根目录、数据库连接和密钥仍为受控启动配置，不通过此表单修改。迁移 `0044_media_settings.sql` 仅在该组不存在时初始化默认配置，不覆盖自定义值；执行后不得改写。升级和备份见 [数据维护](OPERATIONS.md)，回退应用前须确认其支持当前已启用策略。
