# 管理概览

任务失败可通过「查看失败任务」进入统一查询，操作说明见[失败任务](ADMIN_TASKS.md)

审核员和管理员可从账号菜单的“管理概览”进入 `/admin`，选择待处理队列继续审核。管理员还能查看站点近况和运行观测；站点设置保留独立入口 `/admin/settings/brand`。

## 权限和统计

`GET /api/v1/admin/overview` 使用现有 Cookie 会话，返回 `Cache-Control: no-store`。可选 `X-Expected-Account` 用于防止跨窗口切换账号后读取旧账号视图。普通用户无权读取，审核员仅收到待审人设版本、评论和公开资料的计数。举报计数、账号与作品统计、存储和队列观测仅向管理员返回。

读取概览不要求额外的近期身份验证；已经主动绑定 MFA 的账号仍须完成登录验证。角色撤销、账号停用和会话撤销立即由 API 阻断。

审核员和管理员的账号菜单会用红标提示待办，分别标在作品、评论、资料和有权处理的举报入口。菜单使用独立的轻量接口读取真实队列，普通用户没有这项权限。

业务统计在同一 PostgreSQL repeatable read 快照中读取，`asOf` 和 `windowStart` 给出实际时窗，近七天为连续 168 小时。公开作品按当前可见、已审核的公开版本计数；私有草稿、隐藏作品和下架版本不计入。新公开作品使用首次公开时间，发布版本数量包括仍可公开访问的历史版本。

“可用账号”是当前 `active` 账号总数，包含尚未验证邮箱的账号，不代表日活跃人数。有效点赞和收藏排除作者本人、停用或未验证账号、取消关系和未来时间，近七天依据不可变首次添加时间；取消重加不会刷新时间。公开评论只计算仍公开的已批准评论，待审修改不替换旧公开版本。

## 运行观测

业务失败计数来自各业务表；分发耗尽指 Outbox 尚未交付、五次尝试已耗尽且租约未占用的记录。队列采样直接读取配置 BullMQ 队列的失败、等待、执行中及延迟数量。失败阶段可能属于同一个任务，不能直接相加；队列保留的历史失败也不必然代表业务仍未完成。概览只提供观察，重试须使用对应业务的受控入口。

私有文件采样读取配置 Storage 根目录中的普通文件内容大小和文件数，不跟随链接，不包含数据库、Redis、备份或整个磁盘占用。采样限制为十万个目录项、八层子目录和两秒遍历预算，超限标记为部分结果；读取失败显示不可用，不伪装成零。

系统观测最多缓存三十秒，并返回各自 `checkedAt`。采样不与数据库快照构成原子事务，文件持续变化时可能得到部分结果。API 不返回文件名、宿主路径、任务 payload、原始异常、邮件地址或连接凭据。展开“统计口径”或“查看运行详情”可查看这些边界，点击“刷新概览”重新读取业务统计。
